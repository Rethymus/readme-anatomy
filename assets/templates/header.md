# Header template (anatomy.md L1, elements 1–5)

```markdown
# <canonical-name>

*A <category> that <differentiator — what it checks/builds/answers, no adjectives a competitor couldn't claim>.*

<One open question the reader recognizes as their own — no "?"-less statements here.>

[![CI](<workflow badge img>?style=flat-square)](<workflow url>)
[![License](<license badge img>?style=flat-square)](<license file url>)
<!-- ≤ 4 badges total; each href must land somewhere meaningful (gate 4) -->

30 seconds: [Install](#install-anchor) · [Contrast](#contrast-anchor) · [Capabilities](#capabilities-anchor) · [Evidence](#evidence-anchor)
<!-- ordered by the answer to Q2 (what the reader's 30 seconds are for) -->

**English** | [简体中文](README.zh-CN.md)
<!-- only when bilingual (Q4); current language bold, no fragment (gate 5) -->
```

Checklist when using this template:

- [ ] Descriptor names category + differentiator in ≤ 120 chars
- [ ] Hook question is the reader's question, not the project's slogan
- [ ] Badge count ≤ 4, all `flat-square`, no `#` hrefs
- [ ] 30-second path anchors match real headings (gate 1)
- [ ] Project name matches the canonical spelling exactly (gate 3)
