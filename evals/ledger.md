Standing rules (inherited from the house engineering discipline):

- Every rule carries an anchor or is re-derivable from a script — citations
  are acknowledgements, not dependencies.
- PR red line: never loosen a gate threshold to make a document pass.
- Rights review precedes merge: third-party material needs a source and
  license note in `references/research.md` first.
- Release is gated on review approval: an unapproved review blocks the
  tag, it never rides along with one -- v0.10.1 shipped while its review
  was still unapproved because the release step never checked.
- Scripts carrying backslash escape sequences are written with a
  file-writing tool, not assembled through shell text delivery: the
  paths disagree (`echo x\|y` strips the backslash to `x|y`; heredoc
  bodies keep `\|` byte-intact while unquoted ones still expand
  $/backtick -- probed in Git Bash, re-derivable via `od -c`), so
  re-read after any write and assert the exact bytes landed.
